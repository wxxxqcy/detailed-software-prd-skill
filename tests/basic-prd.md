# Basic PRD Regression Test

## Prompt

请生成完整企业合同管理系统 PRD。

角色：
- 销售
- 销售主管
- 法务
- 财务
- 管理员

需求：
- 销售创建合同
- 合同支持附件
- 提交主管审批
- 主管通过后法务审核
- 法务通过后财务审核
- 财务通过后合同生效
- 任意审批节点可驳回
- 销售只看自己的合同
- 主管看本部门
- 管理员看全部
- 合同到期提醒
- 支持续签、作废、归档

## Pass Criteria

- [ ] 有功能架构 Mermaid
- [ ] 有信息架构 / Sitemap
- [ ] 有审批流程 Mermaid
- [ ] 有合同状态机
- [ ] 有完整页面清单
- [ ] 主要页面有 ASCII
- [ ] 页面有字段/按钮/交互/权限
- [ ] 有数据权限
- [ ] 有异常场景
- [ ] 有 Given/When/Then
- [ ] 有 Open Questions
