# Complex Workflow Test

## Prompt

设计采购申请与付款系统：

角色：
- 申请人
- 部门经理
- 采购
- 财务
- 管理员

规则：
- 申请金额小于 5000 元只需部门经理审批
- 大于等于 5000 元需要部门经理审批后再由财务审批
- 审批通过后采购创建采购单
- 收货完成后才能申请付款
- 付款需要财务确认
- 任意审批节点可驳回
- 驳回后申请人可修改重新提交

## Pass Criteria

- [ ] Mermaid 正确表现条件分支
- [ ] 金额规则形成业务规则
- [ ] 状态机没有非法跳转
- [ ] 不同角色按钮与权限一致
- [ ] 驳回重新提交链路完整
- [ ] 收货→付款前置条件明确
- [ ] 页面原型包含审批操作
- [ ] 验收标准覆盖金额边界 4999.99 / 5000
