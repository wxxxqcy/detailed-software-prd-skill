# 权限模型规范

## 1. 权限维度

必须区分：

### 页面权限
能否进入页面。

### 操作权限
能否新增、编辑、删除、审批、导出等。

### 数据权限
能看到哪些记录。

### 字段权限
哪些字段可见、可编辑、只读。

### 状态权限
哪些角色可以推动哪些状态变化。

## 2. 功能权限矩阵

| 功能 | 管理员 | 主管 | 普通用户 |
|---|---|---|---|
| 查看 | ✅ | ✅ | ✅ |
| 新增 | ✅ | ✅ | ✅ |
| 删除 | ✅ | ❌ | ❌ |
| 导出 | ✅ | ✅ | ❌ |

## 3. 数据范围

常见：
- 本人
- 本部门
- 本部门及下属
- 指定组织
- 全部

## 4. 权限失败处理

明确：
- 隐藏按钮
- 显示但禁用
- 点击后提示
- API 层再次校验
- 是否记录越权日志

## 5. 原则

前端隐藏不是权限控制的唯一实现；服务端必须做实际权限校验。
