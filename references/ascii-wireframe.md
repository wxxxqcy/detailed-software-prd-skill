# ASCII Wireframe 规范

## 1. 用途

用于表现：
- 页面布局
- 导航
- 表单
- 搜索
- 筛选
- 列表
- 表格
- 卡片
- Tab
- 按钮
- 分页
- Modal
- Drawer
- Empty
- Loading
- Error

## 2. 基本规则

1. 每个主要 Page 至少一个 ASCII 原型。
2. 重要 Modal / Drawer 单独绘制。
3. 差异明显的状态单独绘制。
4. 重要区域使用编号。
5. 编号必须与“页面区域说明”对应。
6. 原型中的按钮必须在按钮表中定义。
7. 原型中的字段必须在字段表中定义。
8. 原型中的列表列必须在列表字段表中定义。
9. 正文核心操作必须能在原型中找到入口。

## 3. 推荐字符

- `┌ ┐ └ ┘`
- `├ ┤`
- `│`
- `─`
- `[Button]`
- `[Input________]`
- `[Select ▼]`
- `( )`
- `[x]`
- `● / ○`

## 4. 页面示例

```text
┌───────────────────────────────────────────────────────────────┐
│ Logo                     Page Title              User ▼       │
├──────────────┬────────────────────────────────────────────────┤
│ Dashboard    │ ① Breadcrumb / Title                             │
│ Customer ●   │                                                │
│ Order        │ ┌──────────────────────────────────────────────┐ │
│ Settings     │ │ ② Search & Filter                           │ │
│              │ │ Keyword [____________] Status [All ▼]       │ │
│              │ │                          [Reset] [Search]    │ │
│              │ └──────────────────────────────────────────────┘ │
│              │                                                │
│              │ ③ [+ Add] [Import] [Export]                   │
│              │                                                │
│              │ ④ Data Table                                  │
│              │ ┌──┬──────────┬────────┬────────┬───────────┐ │
│              │ │□ │ Name     │ Status │ Owner  │ Actions   │ │
│              │ ├──┼──────────┼────────┼────────┼───────────┤ │
│              │ │□ │ Example  │ Active │ Zhang  │ View Edit │ │
│              │ └──┴──────────┴────────┴────────┴───────────┘ │
│              │                                                │
│              │ ⑤ Selected: 0          ⑥ < 1 2 3 ... >       │
└──────────────┴────────────────────────────────────────────────┘
```

## 5. Modal 示例

```text
┌─────────────────────────────────────┐
│ Delete Record                   ×  │

│ Are you sure?                       │
│                                     │
│ This operation cannot be undone.    │
├─────────────────────────────────────┤
│                  [Cancel] [Delete]  │
└─────────────────────────────────────┘
```

## 6. Empty 示例

```text
┌─────────────────────────────────────┐
│                                     │
│          No data available          │
│                                     │
│             [+ Create]              │
│                                     │
└─────────────────────────────────────┘
```

## 7. 一致性检查

生成完页面后检查：
- 原型按钮 ↔ 按钮表
- 原型字段 ↔ 字段表
- 原型列表 ↔ 列表字段
- 原型筛选器 ↔ 查询规则
- 原型状态 ↔ 页面状态
