# 验收标准规范

## 1. 目标

每个核心功能都需要可测试的验收标准。

## 2. 编号

`AC-P023-001`

## 3. Given / When / Then

### AC-P023-001 查询成功

**Given**
用户已登录，拥有客户查看权限。

**When**
用户输入客户名称并点击“查询”。

**Then**
系统仅展示满足查询条件且位于用户数据权限范围内的客户。

## 4. 必须覆盖

核心操作至少考虑：
- 正常成功
- 必填缺失
- 格式错误
- 权限不足
- 无数据
- 网络/服务失败
- 重复提交
- 状态不允许
- 并发修改（重要场景）

## 5. 禁止

不可测试描述：
- “系统响应要快”
- “体验良好”
- “正常显示”
- “合理提示”

应改成可观察结果。
